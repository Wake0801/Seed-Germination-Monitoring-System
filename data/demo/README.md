# Demo Data

This folder contains a small set of raw Petri-dish images for the web demo.
All images are copied from Faster R-CNN test sequences, so they are not part of
the training split.

Use these files to demonstrate the web flow:

```text
Upload demo image
-> Faster R-CNN scratch
-> bounding boxes + germination states
```
